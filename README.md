A make.fun entry for **One-Line Office Joke: 24-Hour Sprint**: one short joke
about office life, 200 characters at most.

## The joke

> The birthday card has been circulating for signatures since Tuesday, and the birthday was in March.

## How it works

`main.py` (Python stdlib only, deterministic) writes the joke to
`/output/entry.txt`. It validates the text against the bounty gate first:
1–200 characters, UTF-8, a single line, not only whitespace.

```sh
python3 main.py
cat /output/entry.txt
```
